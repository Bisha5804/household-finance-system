# 🏠 Household Financial Health & Expense Advisor System

## 📌 Overview
This project is a web-based financial management system that helps users analyze household income and expenses, calculate savings, and classify financial risk.

## 🚀 Features
- Income & Expense Tracking
- Savings Calculation
- Risk Classification (Safe / Moderate / Risky)
- Expense Visualization (Pie Chart)
- Smart Suggestions

## 🛠️ Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS
- Matplotlib
- Scikit-learn

## 📊 Output
- Total Income, Expense, Savings
- Savings Percentage
- Risk Level
- Suggestions
- Graph Visualization

## ⚙️ How to Run
```bash
pip install -r requirements.txt
python app.py
